Wantzel

A programming language for the code AI agents write.

Compiles in milliseconds, into a dependency-free binary that needs almost no memory to run — and refuses anything it cannot prove correct, out loud. So agents can write code here, and iterate on it in large swarms, on the machine you already have.

Why

You are shipping code you did not write and have only partly read. Plausible code is exactly what a generator is good at producing, so the compiler has to hold what a careful author used to hold.

Four properties, and together they are the point: agents can write code here, and iterate on it in large swarms — on ordinary hardware.

  • Compile speed — the compiler compiles its own 6,500 lines in about 9 ms. Fast enough to compile on every change, which is what makes iterating possible at all. How fast depends on what the source is made of — by a factor of sixteen — so the suite reports a rate per shape rather than one number.
  • Dependency-free binaries — one static binary, and the programs it produces are the same. Nothing to install per agent, so there is nothing to isolate and nothing to tear down.
  • Low memory at run time — no runtime, no garbage collector, no virtual machine. Fifty agents fit on the machine you already have.
  • A strict, verbose compiler — what it refuses is what nobody has to review, and what it accepts it accepts in silence. Otherwise: the file, the line, and the reason, in a form an agent can act on without a human reading it first.
  • HTTPS without linking anything — TLS 1.3 is written in the language itself: the handshake, X25519, ChaCha20-Poly1305, ECDSA, RSA, chain verification and a trust store. A complete HTTPS client is a 287 kB static binary that fetches from github.com, cloudflare.com and letsencrypt.org over a fully verified connection, and refuses one whose certificate does not match the name. No OpenSSL, no certbot. There is no DNS resolver, so a client is given the address and the hostname separately.

Two languages shaped this one: Turbo Pascal, for what a short loop feels like — you pressed a key and your program ran, so you iterated in thought rather than in waiting time. And Go, for the shape of the thing you ship: a static binary with no runtime to install. The loop from one, the artifact from the other.

Where to go next

The repository holds the language reference, the reasoning behind the design, and worked examples — among them an MCP server, an HTTP server, an HTTPS client and server, a file server over MCP and an OAuth flow, each a single file you can read in one sitting.
