Wantzel

A programming language built for AI-written code.

Wantzel compiles in milliseconds to small, dependency-free binaries. Strict checks and clear errors help agents correct mistakes after every change.

View the source on GitHub. With Wantzel AI Studio, you can run and supervise coding agents in one workspace.

Try it

Why

AI-generated code can look correct while still containing mistakes. Wantzel rejects invalid programs early and reports the file, line and reason.

  • Fast feedback — compiles its own 8,100 lines in about 10 ms.
  • No dependencies — the compiler and generated programs are static binaries. No packages or runtime to install.
  • Clear errors — rejected code reports the file, line and reason.

Explore

Read the language reference or browse complete examples, including MCP and HTTP servers, an HTTPS client and server, a file server and an OAuth flow. TLS 1.3 is written in Wantzel itself, without OpenSSL.
